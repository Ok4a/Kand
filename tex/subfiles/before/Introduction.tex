The problem of matrix inversion for linear systems, is a problem that aries in many fields of numerical study. Our interest comes from the study of Quantum Chromodynamics with the model Lattice QCD. Where matrix inversion comes from the need of the application of the inverse of the Dirac operator, \(D\), onto a vector. Which can be done with the method conjugate gradients. In exact arithmetic conjugate gradients uses a maximum number of iterations equal to the dimension of the system it is used on \cite{Vorst03} as the approximation is created from a linear combination of orthogonal vectors.

Because the numerical studies are not done in exact arithmetic. A general convergence of conjugate gradients can be derived from the error of the approximation such that it is bounded by the condition number of the matrix from the linear system, \(\kappa(A)\). Meaning that system with larger condition number have a slower convergence than a system with smaller condition number. Therefore when using method such as conjugate gradient and its variants, if the linear system is transformed with a preconditioner such that the new systems condition number is much smaller and also therefore has a faster rate of convergence.

Construction of a good preconditioner is difficult as it needs to decrease the iteration count enough such that the extra computational cost of using a preconditioner does not increase the total running time of the linear solver. A good preconditioner is also often unique to the system. Therefore if there is the need to precondition many slightly different systems, a unique preconditioner has to be constructed for each system. Depending of the preconditioner this can range from almost trivial to as difficult as inverting the system itself and this is often directly correlated to how much the preconditioner reduce the solver iteration count by. This is where the idea behind this project comes from. If you could use a Machine Learning type algorithm to learn a preconditioner, to capture some potential underlying structure of a set of similar linear systems, such that the preconditioner on average works well on all of the systems. You would only need to learn a preconditioner once for each set of similar systems. This is what we will try to accomplish in this thesis.
