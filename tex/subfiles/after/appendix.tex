\subsection*{6.1 \ \ Code and data}
In the append zip file \texttt{code\_and\_data.zip} is the code, the data used for this project and the Matrix Market matrices used. In the data folder the data is sorted in roughly the the same manner as the section it was shown in. The main code files are: \texttt{precondLearn.py} the file that contains the learning algorithm; \texttt{Precondition.py} the file for generating and updating the preconditioners; \texttt{linearSolver.py} for out implementation of the linear solver; \texttt{genLaplace.py} the file that generated the 2-dimensional discrete laplace operators with perturbations; two utility files \texttt{util.py} and \texttt{genConfig.py}; a subfolder with every file that generated the plots. The rest of the files was made to make some small test.
