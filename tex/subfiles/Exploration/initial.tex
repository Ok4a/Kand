The base idea is to take a basic machine learning type approach, similar to how neural nets are learned, where we try to learn a preconditioning matrix, that hopefully can learn some underlining structure of matricis of the data set. To do this we start with a simple random matrix and use it as the preconditioner for systems in the data set. Then in each of the iterations of the learning we change the preconditioner by some amount and solve the systems to see if the change is better according to some improvement function.
